# Finished videos

- `test/` – the 5-second brand test animation (30 and 60 FPS)
- `reels/` – promo reels made with `npm run reel` (plus the `.props.json` used, so a reel can be re-rendered)
- `instructional/` – rotation and rules videos made with `npm run render`

Every file is checked with FFprobe after rendering: 1080×1920, H.264, yuv420p, 30/60 FPS.
