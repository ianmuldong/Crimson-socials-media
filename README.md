Crimson Media

AI-powered video production and motion graphics system for Crimson Volleyball Club.

Project Objectives

* Friday Socials promotional videos
* Animated volleyball court rotations
* Animated rules and instructional videos
* Cinematic volleyball highlight reels
* Tournament promotions
* Player introductions
* Sponsor advertisements
* Reusable weekly social media content

Technology Stack

* Remotion
* FFmpeg
* FFprobe
* React
* TypeScript
* Node.js
* Claude Code

Brand Identity

* Crimson red, deep maroon, black and white
* Premium sports commercial aesthetic
* Cinematic colour grading
* Bold athletic typography
* Professional motion graphics

Video Specifications

* Instagram Reels and TikTok
* Vertical 9:16 format
* 1080 × 1920 resolution
* 30 or 60 FPS
* High-quality MP4 exports

Development

Claude Code will configure the environment, install dependencies, develop reusable video templates and establish the video rendering workflow.
