# Organiser logos (all three are equal partners)

Save the official files here with exactly these names:

| Organisation | File name |
| --- | --- |
| Chequers Volleyball Club | `chequers.png` |
| Crimson Volleyball Club | `crimson.png` |
| DO Volleyball | `do-volleyball.png` |

- Use transparent PNG (at least 1000 px on the long side) or SVG (rename the path in `src/campaign/config.ts`).
- The videos show each file **unchanged**: same proportions, colours and design, inside identical square slots.
- Until a file is present, its slot shows "LOGO PENDING". Nothing is generated or redrawn.
- To swap a logo later, overwrite the file with the same name and re-render.
