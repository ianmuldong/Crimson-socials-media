# Sound effects

The `.wav` files here were synthesised from scratch with FFmpeg for this project
(no third-party samples), so they are free to use anywhere:

- `whoosh.wav` – transitions
- `bass-hit.wav` – headline impacts
- `whistle.wav` – end-of-game whistle (synthetic referee pea-whistle)
- `ball-impact.wav` – ball contact accent
- `riser.wav` – build-up into a reveal
- `tick.wav` – clock / countdown tick

Replace any file with a better licensed sample under the same name and every video picks it up.
Real crowd noise and shoe squeaks come from your footage's own audio.
